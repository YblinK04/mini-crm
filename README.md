🚀 RealTask
**Live Demo:** [real-task-v2.vercel.app](https://real-task-v2.vercel.app/)

RealTask - это современная Full-stack платформа для управления проектами и задачами, построенная на архитектуре Next.js 15. Проект ориентирован на высокую производительность, реактивный UI и надежность данных.

🛠 Технологический стек

- Framework: Next.js 15 (App Router) + React 19
- Auth: Auth.js v5 (NextAuth) - кастомные сессии и JWT.
- Database: Neon DB (PostgreSQL) + Prisma ORM.
- State Management: Zustand (Client State) + TanStack Query v5 (Server Cache).
- UI & Styling: Tailwind CSS + Shadcn UI + Framer Motion.
- Kanban Engine: @dnd-kit с поддержкой сенсорных устройств.
- Uniti тесты с помощью Vitest
  💡
  Ключевые технические решения (Interview Highlights)

В ходе разработки были решены следующие инженерные задачи:

1. Гибридное управление состоянием
   Реализована синхронизация серверного кэша и клиентского стейта. Использование TanStack Query совместно с Zustand позволило добиться мгновенного обновления интерфейса (Sidebars, Dashboards) при совершении мутаций без принудительной перезагрузки страниц.

2. Целостность данных и транзакции
   Все критические операции (создание проекта вместе с системным уведомлением, удаление с очисткой связей) обернуты в Prisma Transactions. Это гарантирует отсутствие «мусорных» данных в БД при сбоях.

3. Продвинутая авторизация
   Расширена базовая логика Auth.js: реализована синхронизация профиля пользователя (имя, аватар) в реальном времени через механизм session update и кастомизацию JWT-токенов.
4. Адаптивная Kanban-доска

Разработан кастомный интерфейс доски с поддержкой Mobile First подхода. Использованы Pointer и Touch сенсоры для корректной работы Drag-and-Drop на смартфонах и планшетах.

5. Система уведомлений и Глобальный поиск
   Реализован быстрый поиск по проектам и задачам через Command Palette (Ctrl+K) и система реактивных уведомлений, информирующая пользователя о ключевых событиях в системе.

🚀 Быстрый старт

- Клонируйте репозиторий: git clone ...
- Установите зависимости: npm install
- Настройте .env (DATABASE_URL, NEXTAUTH_SECRET)
- Выполните миграции: npx prisma db push
- Запустите проект: npm run dev
